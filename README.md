# WayFix

WayFix 用于修复 Paper 1.21.11 服务器发送异常航点更新包，导致客户端在处理 `clientbound/minecraft:waypoint` 时断开的问题。

## 安装

1. 在每个 Paper 后端服务器的 `plugins` 目录安装 PacketEvents 2.13.0。
2. 将 `PLUGIN/WayFix-1.0.1.jar` 复制到同一个后端服务器的 `plugins` 目录。
3. 重启服务器。

本插件只安装在 Paper 后端，不安装在 FlameCord 代理端。

## 修复逻辑

- 航点新增包会登记航点标识并正常发送。
- 航点更新包只有在对应航点已经登记后才会发送。
- 没有对应新增记录的异常更新包会被拦截。
- 航点删除包会清理登记并正常发送。

航点标识同时支持 UUID 和字符串。插件会在玩家加入游戏、重生、退出或被踢出时清理对应状态。

## 配置

`config.yml` 中的 `log-blocked-updates` 默认关闭。开启后会记录被拦截的异常更新包，日志按玩家和异常类型限频。

所有插件日志和配置说明均为中文。
